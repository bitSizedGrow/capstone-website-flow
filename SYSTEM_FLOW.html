PPMIS — how the system loads, per action

Every user action, traced from the click to the files that answer it, then split into 7 parts so each teammate owns a section they can explain. 53 actions in total: 53 ÷ 7 ≈ 7.6, so four parts have 8 actions and three have 7. Parts with heavier files (the workspace, amendments) got the 7s.

How to read each action: the chips show the flow in one line. The numbered list under it is where to look, as file:line, in the order the code runs. Open the file, jump to that line, and read until the next item. Line numbers are from the current main branch and will shift a little as the code changes. If one has moved, search for the function name shown next to it.
Out of scope, as requested: modules/report/generate.php and the classes only it uses: DocTemplate, DocTemplates, DocTables, DocTableEditor, DocInputDoc, DocExport, GeneratedDocs, ReportData, RevisedAnnexD. Pages that only link to the generator (Reports, the workspace, amendments) are still covered.

The load pipeline every page shares

Every page in modules/ and the root follows the same order. Each part below shows only what is different for its actions.
